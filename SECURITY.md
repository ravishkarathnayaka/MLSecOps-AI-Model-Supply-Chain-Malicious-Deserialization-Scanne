# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of machine learning supply chains seriously. If you discover a vulnerability or sandbox bypass in this project:

1. **Do NOT open a public GitHub Issue.**
2. Send an email with a detailed Proof-of-Concept (PoC) to the repository maintainer.
3. You can also utilize GitHub Private Vulnerability Reporting directly on this repository.

### Response Time

- **Acknowledgment:** Within 48 hours.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Disclosure:** Coordinated release with CVE assignment where applicable.
