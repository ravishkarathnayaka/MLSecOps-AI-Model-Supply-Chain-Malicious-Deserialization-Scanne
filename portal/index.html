Model Supply Chain Threat Matrix

Static detection rules engineered against primary AI/ML weaponization techniques and deserialization exploits.

CRITICAL .pkl / .pt
Pickle __reduce__ Execution
Injecting arbitrary Python callables into deserialization streams to spawn shells upon weight loading.
cos.system / cbuiltins.eval
CRITICAL .pt / .zip
Zip Slip Directory Traversal
Archive filenames containing traversal sequences that overwrite critical system files on host extraction.
../../../../etc/shadow
CRITICAL .onnx
Adversarial ONNX Operators
Computational graphs importing custom unvetted domains to invoke native execution primitives like ExecutePayload or PyOp.
domain: custom.adversarial
CRITICAL .safetensors
Out-of-Bounds Buffer Offsets
Tampered header offset ranges claiming memory bounds past physical EOF to trigger runtime segmentation faults.
data_offsets: [0, 9999999]
CRITICAL .pkl / .pt
Network Exfiltration Primitives
Embedded socket connections or urllib handles established during checkpoint loading to exfiltrate GPU data.
csocket.create_connection
HIGH .pt / .bin
Embedded Standalone Binaries
Model archives secretly packing standalone shell scripts, ELF binaries, or Windows DLLs beside weights.
archive/run_payload.sh
